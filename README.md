# superwho-home

Public SuperWho.io homepage (GitHub Pages).

This repository is separate from `superwho-launch`, which continues to serve launch.superwho.io. Do not change launch, detroit, or progress DNS records when pointing superwho.io here.

Custom domain: `superwho.io` (and `www.superwho.io`). After DNS is updated, turn on Enforce HTTPS in Pages settings once the certificate has been issued.
